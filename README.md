# Lapsen huollosta ja tapaamisoikeudesta annetun lain (361/1983) kommentaari

Kommentaari suomalaiseen säädökseen: **Laki lapsen huollosta ja tapaamisoikeudesta 8.4.1983/361**. Kommentaari kattaa **79 pykälää** (1–7 luku ja 3 a luku, mukaan lukien myöhemmin lisätyt a–d-pykälät sekä voimaantulo- ja soveltamissäännös) **3 kommentaarin luvussa**; kunkin pykälän kohdalla esitetään säännöksen sanamuoto sellaisenaan ja sen jälkeen kommentaari.

Tekstin tila: Finlexin ajantasainen lainsäädäntö, versio **20250552** (ajantasaistettu **27.6.2025**, viimeisin lähteessä mainittu muutos L 27.6.2025/552, voimaan 1.1.2026).

## Menetelmä

Kommentaari on laadittu **yksinomaan paikallisten aineistojen perusteella** (Finlexin avoimen datan ajantasainen säädösteksti), ilman kaupallisia oikeudellisia tietokantoja. Säännösten sanamuoto on siirretty lähteestä koneellisesti ja sanatarkasti. **Oikeuskäytäntö ei sisälly tähän versioon** — se lisätään erillisessä vaiheessa.
